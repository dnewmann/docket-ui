# Changelog

All notable changes to `@dnewmann/docket-ui`. Versions follow semver.

## 0.2.0

- 17 new components: **Tabs**, **Tooltip**, **NumberField** (currency, percent, decimal), **Stat**, **Badge**, **Skeleton**, **Card**, **Alert**, **SegmentedControl**, **RadioGroup**, **Textarea**, **Spinner**, **EmptyState**, **Pagination**, **Menu**, **Progress**, **Accordion**.
- The build now starts with `'use client'`, so components work in Next.js App Router and other Server Component frameworks.
- New component tokens for tabs, tooltip, stat, badge, skeleton, card, segmented control, progress and menu; new contrast checks for stat deltas, the tabs indicator and tooltips.
- Publishing runs from GitHub releases with npm provenance.

## 0.1.0

- Tokens (primitives, semantic, component), contrast gate, and Button, TextField, Select, Checkbox, Switch, Modal, Combobox, Table.
- Patterns: matter intake form, matters dashboard, desk booking with guided tour, AI assistant.
