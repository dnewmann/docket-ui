## What's inside

- **Tokens:** primitives, semantic tokens (light and dark) and component tokens, in JSON. One build step turns them into CSS variables.
- **Components:** 25 React and TypeScript components, styled only with tokens: form controls (TextField, Textarea, NumberField, Select, Checkbox, RadioGroup, Switch, SegmentedControl), overlays (Modal, Menu, Tooltip), data display (Table, Stat, Badge, Progress, Card), navigation (Tabs, Pagination, Accordion), feedback (Alert, Spinner, Skeleton, EmptyState), plus Button and Combobox. Each one has tests for behavior and accessibility.
- **Install:** `npm install docket-ui`, then import `docket-ui/styles.css` once.
- **Patterns:** real screens assembled only from the library: a matter intake form, a matters dashboard, desk booking with a guided tour, and an AI assistant with saved chats and prompts.

## Principles

1. **Tokens, never raw values.** A brand or theme change happens in one JSON file.
2. **Accessibility is a build gate.** Every text and control color pair is checked against WCAG AA in both themes, components are tested with axe, and stories fail on accessibility violations.
3. **Native first.** Use the platform (`<button>`, `<select>`, `<input type="checkbox">`) and add only what it is missing, so keyboard and screen reader support come for free.
4. **One primary action per view.**
5. **Minimal color, generous space.** Neutrals do the work; violet marks focus and selection; the aurora gradient is reserved for one highlight per view.
