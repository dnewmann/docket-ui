## What's inside

- **Tokens:** primitives, semantic tokens (light and dark) and component tokens, in JSON. One build step turns them into CSS variables.
- **Components:** React and TypeScript, styled only with tokens. Each one has tests for behavior and accessibility.
- **Patterns:** real screens assembled only from the library, like the matter intake form.

## Principles

1. **Tokens, never raw values.** A brand or theme change happens in one JSON file.
2. **Accessibility is a build gate.** Every text and control color pair is checked against WCAG AA in both themes, components are tested with axe, and stories fail on accessibility violations.
3. **Native first.** Use the platform (`<button>`, `<select>`, `<input type="checkbox">`) and add only what it is missing, so keyboard and screen reader support come for free.
4. **One primary action per view.**
